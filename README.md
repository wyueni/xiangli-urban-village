# 巷里

**一款以广州康鹭街巷为视觉参考的 3D 城中村更新小游戏。** 玩家在虚构社区里走访、观察，再用有限预算安装路灯、改善排水或调整建筑，比较每种改造对街坊生活的影响。

## 快速体验

- **在线试玩** [巷里网页版](https://wyueni.github.io/xiangli-urban-village/)，启用 GitHub Pages 后可直接在浏览器中打开。
- **离线试玩** 下载仓库 ZIP，解压后双击 `开始体验.html`，使用支持 WebGL 的浏览器。
- **本地开发** 在仓库根目录运行 `node server.cjs`，再在本机浏览器打开 `http://127.0.0.1:4175/`。

## 这一版的变化

- **街巷和建筑**采用 Blender 烘焙的墙地纹理及倒角电动车外壳。近处和远景楼补充了窗框、窗台、空调外机和部分窗帘。
- **昼夜切换**在夜景中分散点亮约四成住宅窗户，并混合暖黄、暖白和偏冷的窗灯。
- **路灯选址**从改造商店选择路灯，点击三维场景的地面。看到灯杆和价格后，点击「确认安装」。点到主通道或建筑时，可用「找附近空位」，让游戏在三米内给出候选点。

## 一局怎么玩
1. 新局从 **1500 万元总预算** 开始，改造和运营共用这笔钱。点击「结算本月」后，100 万元政府拨款和当月经营收入入账，并扣除维护费与排班费。先走访祠堂、肠粉档、茶桌、工坊、讲古角和便民点。
2. 点击民居可花 18 万模拟预算整修立面。点击隐患可查看改善方式和价格。
3. 在「改造商店」选择设施，进入三维场景或地图选址。确认安装后扣款，并在账本中记录。
4. 不能压住现有民居、河涌、主要通道或祠堂前埕。民居可整修、拆除腾地或退界重建。拆建含教学安置成本，可在账本查看容量缺口。
5. 新增设施可选中后搬迁或拆除；早餐档可选择新的可用位置搬迁。祠堂不作为可拆迁对象。
6. 用“撤销”恢复上一步的预算和场景；账本可导出方案JSON。浏览器允许本地存储时会保存本机进度；刷新后不保留撤销历史。JSON为导出记录，本版没有JSON导入界面。
7. 默认白天；昼夜同视角对照、街巷自由观察、单栋GLB导出继续保留。

## 全景地图
全屏地图标注主路、商业巷、横巷、河涌、前埕、20栋民居、11个原有生活文化/观察节点，以及玩家新增设施。
支持搜索、地点目录、点击定位、滚轮/按钮缩放、拖动平移和全图复位。生活文化、示意雨洪敏感性、中层冬至直射日照、步行服务覆盖使用同一套游戏位置数据。不是高德底图，也不提供真实导航。

## 地理如何成为机制
- **自然地理与生态**：树冠覆盖与下垫面分开观察，新增树木不自动被算成透水铺装。
- **灾害与环境**：可选择30/60/100毫米的一小时教学降雨情境。透水铺装和雨水花园的示意产流差值按新增面积×假定径流系数差×降雨量计算。不是SCS-CN、SWMM或管网模型，不预测水深。
- **人文与经济地理**：原有住宅、早餐档、交往节点和手艺工坊保留。叙事包含居民与外来劳动者，避免把社区等同于问题集合。
- **城乡规划**：预算、用地、连续通路、文化空间和居民日常构成约束。自由选址有代价，不能无限新增或覆盖既有功能。
- **GIS**：便民驿站选址会改变简化路网最短距离，进而改变80米阈值内的示意住户服务覆盖。住户权重按楼层生成，不是真实人口。
- **建筑环境**：原有20栋民居前立面低/中/屋顶采样天空遮挡代理。只计算简化主体，忽略窗洞、室内、新设施、树冠和雨棚；不等于日照小时数、室内照度或合规结论。
- **文化传播**：祠堂、早餐、广绣、粤语讲古带预写中英说明，强调生活语境、来源与创作者。广府是大湾区多元文化的重要部分，不代表大湾区全部文化。没有真实订单、营收或出海效果预测。

## 模型范围
- 树冠覆盖：固定范围网格与简化圆形树冠的交集示意，不是法定绿地率。
- 雨洪地图：合成的南端低洼趋势、局部排水口维护项和新增透水设施影响项；没有真实DEM和水力汇流。敏感性不等于完整灾害风险，暴露与脆弱性没有量化。
- 选址碰撞：二维包围盒与预留区域检查，不能替代真实规划审查；忽略部分装饰、树冠和线缆。
- 自由行走仍无碰撞与事故模拟。标价均为模拟参数；预算和保存均在浏览器本机运行。
- 没有后端、账户、在线协作、真实市场交易或大模型内容生成。

## 开发
- `dist/scene.js` 负责街区场景、生活节点、采光模型和三维交互。
- `dist/blender-assets.js` 保存游戏使用的 Blender 纹理和电动车外壳几何。
- `dist/budget.js`：纯状态、目录、定价、事务、撤销和存档校验；金额内部以0.1万元整数存储。
- `dist/planning.js`：自由放置、商店、地图、生活叙事、服务与雨洪教学对照。
- `dist/export.js`：单栋静态GLB导出，保留基础颜色PNG与基本PBR材质，不导出程序bump效果。
- [SOURCES.md](SOURCES.md) 列出公开参考资料和采用范围。
- [LEARNING_GUIDE.md](LEARNING_GUIDE.md) 介绍地理概念和对应玩法。
- `window.Xiangli.planning`：后续整合接口。

Three.js的MIT许可保留在 `dist/vendor/THREE-LICENSE.txt`。

## V04补充：专业词条与可选公众便签
- 26个中英专业词条：定义、场景联系、当前游戏采用范围、检索词和延伸阅读。包含自然水文、城市微气候、GIS网络分析、人文地方依恋、产业集聚、文化参与和规划权衡。
- 相关理论不等于已实现的算法。SCS-CN、标准SVF、完整区位—分配求解等明确标为延伸学习或相关理论。
- 每个既有地点和民居可在侧栏填写便签；新增设施可在物件窗口填写理由；地图任意位置可添加紫色位置便签；账本可写整份方案说明。
- 便签完全自愿、免费，留空不影响改造。保存或删除便签也是一项可撤销的方案操作，但不会扣款。
- 导出的JSON与Markdown讨论材料包含模拟位置、费用、理由、方案清单和指标范围。局部坐标无法直接定位真实场地。
- 本版不自动上传、不收集账号，也没有集中方案征集后台。由用户决定是否分享；实际应用须经过场地核验、居民协商与专业评估。
- 独立浏览器UI测试已验证专业词条展开、定义与来源展示，以及地图创建便签后出现在地点目录。测试不验收WebGL画面。
- `dist/knowledge.js` 与 `LEARNING_GUIDE.md` 可供组员补充或审校内容。

## V05 方案对照

- 选建筑可比较两种拆建方案，点击楼层日照观察查看改造前后。原有街坊便签继续可用。
- 容量模型按每层住宅面积的72%及24平方米/间估算房间数，再乘每间入住人数。默认两人，可在账本切换一至三人。冬至直射日照采用广州纬度，计算临街立面三点平均，遮挡只计民居体块。
- 地面种植率与树冠投影分别统计，分母固定为街区中部77 × 116米。
- 广府导览提供四站的中英说明、粤拼与空间讨论问题，支持导出。

## V06 边玩边验证

- 施工前可预测，施工后看实际变化，再从结果页撤销并试另一处。驿站用路网距离，拆建用邻楼逐层日照，雨水花园和透水铺装用简化产流模型。
- 三维场景可选原有物件，地图的「可编辑街巷物件」图层可集中查找。民居可按原型迁建。独立电动车、树池、矮凳、垃圾箱、流动摊车与多数生活设施可搬迁或撤除，按物件标价。
- 河涌、祠堂前埕与接入地下管线的设施保留原址。建筑附属件随所属建筑处理；背景网格、路面标线和架空线路不作为独立编辑对象。

观察面板与全景地图的雨洪、楼层日照和绿化图层带有诊断卡。卡片解释形成机制、常用措施与适用条件，可从卡片直接走访或选址。日照占比用 ≥60 分钟作为教学比较阈值，按各方案仍存在的楼层统计。
